# Program Feedback Dashboard

A one-page dashboard that turns open-ended survey responses into themes a program team can act on the same week.

> Demo build. Every response, quote, count, and name here is invented. No real participant data is included.

## The problem

End-of-year surveys for a cross-district leadership network came back as long, open-ended answers. Read one by one, they blurred together. The team needed to see what was working, what people needed next, and which single voices deserved attention even though they weren't the majority.

## What it does

- Codes open-ended answers into themes and charts them by frequency, for strengths and for needs
- Groups the open suggestions into short cards with a count, so the team can scan them in a minute
- Pulls out a "signal watch" section for outlier and dissenting voices, including the contrarian view, so a small but important signal doesn't get averaged away
- Works on a phone as well as a laptop, so it can be shared straight into a planning meeting

## How it was built

Single HTML file with Chart.js. The coding and theming were done from the raw responses, then the page was built to tell the story of the data rather than just display it.

## Try it

Open `index.html` in a browser.

## What I'd note for a product team

This is the same job a customer success lead does with support tickets and feedback forms: find the patterns, protect the outliers, and hand the product team something specific enough to build on.
